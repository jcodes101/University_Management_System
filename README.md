### what each class does

Class Responsibility
Student Stores name, ID, phone, address, enrolled courses, and GPA
UndergraduateStudent Supports undergraduate course registration
MSStudent Supports courses and MS project registration
PhDStudent Supports courses, MS project, and dissertation registration
Course Stores course code, name, credits, and grade
UniversityManager Manages students, courses, and registrations
UniversityGUI Displays windows, buttons, forms, and results
Main Launches the application
